# 06counter · 市集收银

把商品表导进来，然后像按计算器一样点商品。

这是 v3 极简收银版本。纯静态 PWA，适合手机浏览器及添加到主屏幕使用，不需要账号或服务器。保留了商品宫格、长按换位和卡片尺寸调整。

## 本地运行

```sh
npm start
```

打开 http://localhost:4173 。本项目无需构建。请通过 HTTP 服务打开，直接双击 HTML 不支持 JavaScript 模块及离线缓存。

## 使用

1. 在「商品」页选择 Excel，软件自动寻找商品表、表头、名称和售价，直接展示预览。核对后确认导入，商品自动加入收银宫格。也支持无表头表格与 CSV。
2. 或手动添加商品，仅填写名称和价格。新安装不会自动添加示例商品或示例流水。
3. 点击商品累加当前订单，进入当前订单调整数量、删除或添加临时金额。没有商品也可以从收银页左上角直接添加临时金额。
4. 进入大数字结算，向顾客展示金额。点击「完成收款」保存流水，然后开始下一单。
5. 在「流水」页按日期查看销售汇总与商品明细、导出 Excel。不会在每次点击商品时记一笔销售。
6. 在「设置」中调整宫格、备份/恢复数据、按范围清空数据。编辑模式长按 400ms 可拖动换位，拖动右下角调整大小；轻点卡片可用表单操作，兼容键盘。

导入限制：10 MB、每张表 10,000 行、100 列。名称最多 80 字，单价为非负金额，最多两位小数、最高 ¥999,999.99。可识别 `15元`、`￥15`、`15元/件` 等常见价格格式；真实的超过两位小数金额不静默舍入。缺价、负价等异常保留并标红，可直接在预览里修改或明确跳过，无需修改原文件。导入采取追加方式，不按同名商品覆盖。

## 自动识别与确认

- 自动扫描前 40 行寻找表头，结合列名及实际内容识别名称与价格，避免把序号、库存、总金额当作售价。每次只导入一张商品表；多张表都有商品时集中选择一次。
- 零售价与成本价并存时优先识别零售价；零售价/批发价并存，或只找到采购价/进货价时，必须明确选择收银价格。
- 标题、说明、重复表头和合计行会自动跳过，并展示跳过的行号与原因。未知异常保留在预览，不能带错误确认导入。
- 预览每页 50 件商品，支持逐件改名、改价、跳过和恢复。切换价格列保留改名与跳过状态，单价重新按所选列读取。
- 默认不显示列映射；「识别不对？调整识别范围」提供手动兜底。更换工作表或手动调整识别范围会重新生成预览，并重置本次修改。
- 全部为本地规则，无模型调用费，不上传文件。图片价目表、嵌入截图、多个并排商品区域及复杂多层表头不在本轮自动识别承诺范围；不确定的模板保留手动确认。

## 数据与旧版兼容

- 新版使用 `06counter-checkout-v3` 本地存储键；商品单价和订单金额以**整数分**保存，导入/输入显示单位为元。
- 商品、当前订单与流水保存在同一份状态中。保存失败不会清空当前订单，也不会显示收款成功。
- 首次访问会复制旧版 `counter-app-v1` 中的商品及卡片尺寸。旧版历史按每日计数保存，不能还原为订单，因此不会转成新版成交流水。
- `legacy.html` 保留完整旧版（含激活码体系、旧 CSV 导出及原存储键），可从设置进入。旧版数据与激活状态不会被新版清空。
- 编辑/删除商品不改变当前订单及已完成订单的商品名称、单价快照。
- 不同窗口会同步本地数据。检测到未同步的写入时拒绝覆盖并提示刷新。
- 浏览器数据被清除或设备丢失可能导致记录丢失。活动结束请保存 JSON 备份；恢复会替换新版数据，并要求确认。

## 销售流水与 Excel 导出

流水按日期查看，每笔直接显示成交时的商品名称、单价、数量和小计，包含临时金额。商品后续改名、改价或删除，不会改变已保存的交易明细。

「导出 Excel」下载所选日期的 `.xlsx` 文件，包含三张工作表：销售汇总（日期、销售额、成交笔数、商品件数）、订单流水（订单编号、成交时间、件数、总金额）、商品明细（订单编号、成交时间、商品名称、单价、数量、小计）。金额为以元计的数值，支持 Excel 汇总计算；商品明细不重复列出订单总额，避免求和重复计入。离线也可导出。当前收银版用 Excel 替代 PDF 导出；JSON 备份继续保留完整数据。

## 测试

需要 Node.js 22+；浏览器测试需要 Chromium。

```sh
npm ci
npx playwright install chromium
npm test
# 另一个终端先运行 npm start
npm run test:browser
npm run test:edges
npm run test:import
npm run format:check
```

测试数据与截图写入 `/tmp/06counter-test`，仅在自动化浏览器的隔离存储中创建，不修改日常使用的数据。可用 `TEST_URL`、`TEST_OUTPUT` 自定义服务器地址和测试输出目录。

覆盖：完整 ¥86 收款流程、临时金额、十进制精度、重复完成、持久化失败、刷新恢复、旧版迁移、XLSX/XLS 导入、错误预览、无表头映射、商品编辑/删除、宫格换位/缩放、备份恢复、320/390/768px 布局、长名称/大金额、按日筛选、多笔订单 Excel 明细、离线启动/导入/导出。

## 结构与依赖

- `index.html`：应用入口。
- `src/app.mjs`、`src/styles.css`：页面与交互。
- `src/model.mjs`：商品、订单、本地存储、金额计算和表格校验。
- `src/import.mjs`：Excel 读取。
- `src/import-detect.mjs`：工作表、表头、名称、价格识别与清理。
- `src/import-panel.mjs`：预览、歧义选择、纠错与手动兜底。
- `src/report.mjs`：销售汇总与商品明细 Excel 导出。
- `sw.js`：缓存本地页面、模块和依赖，支持根目录及 `/06counter/` 等子目录部署。
- `vendor/xlsx.full.min.js`：SheetJS CE 0.20.3，Apache-2.0。来源：[SheetJS 官方独立脚本](https://docs.sheetjs.com/docs/getting-started/installation/standalone/)。
- `vendor/jspdf.umd.min.js`：jsPDF 3.0.3，MIT。来源：[jsPDF 官方项目](https://github.com/parallax/jsPDF)。

SheetJS 已随项目保存，无需运行时访问 CDN，按需加载并预缓存。jsPDF 为早期 PDF 功能遗留文件，新版不再加载。开发依赖仅用于格式化和自动化测试。
